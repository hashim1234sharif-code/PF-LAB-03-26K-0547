# C Basics

## 1. Data Types

- `int` - stores whole numbers.
- `float` - stores decimal numbers.
- `double` - stores decimal numbers with higher precision.
- `char` - stores a single character.
- `bool` - stores true or false.
- `void` - represents no value.

## 2. Format Specifiers

- `%d` - integer
- `%u` - unsigned integer
- `%o` - octal
- `%x` - hexadecimal
- `%X` - uppercase hexadecimal
- `%f` - floating-point
- `%e` - scientific notation
- `%c` - character
- `%s` - string
- `%ld` - long integer

## 3. Input/Output Functions

`scanf()` - takes input.

`printf()` - displays output.

`getchar()` - reads one character.

`putchar()` - displays one character.

`fgets()` - reads a line of text.

`puts()` - displays a string.

## 4. Escape Sequences

- `\n` - new line
- `\t` - tab
- `\\` - backslash
- `\"` - double quote
- `\'` - single quote

## 5. Precision

Precision controls the number of digits after the decimal point.

Example: `%.2f` displays two decimal places.

`printf("%.2f", 12.3456);`
